# ديوان وموقع الشاعر ذو النون أحمد نايل (الدرويش) 📜✨

الموقع الرسمي والديوان الرقمي التفاعلي للشاعر والإعلامي السوداني **ذو النون أحمد نايل**.

![صورة الشاعر](assets/images/poet_portrait.jpg)

## 🌟 مميزات الموقع
- **هوية ملكية داكنة (Dark Obsidian & Antique Gold)**: تصميم أنيق وعصري مريح للعين مع تأثيرات الزجاج المصقول (Glassmorphism).
- **ديوان القصائد التفاعلي**: تصنيف فوري وبحث لحظي في نصوص وقصائد الشاعر (هسي قولا، حواس، شنو الريد، بالله كيف، ضاريتك، وغيرها).
- **نافذة القارئ الفاخر (Modal Reader)**: تكبير وتصغير حجم الخط، نسخ فوري للمقطع أو القصيدة كاملة، ومشاركة مباشرة.
- **بث مباشر من صفحة فيسبوك**: ربط مباشر مع صفحة الشاعر الرسمية لعرض منشوراته وقصائده لحظة بلحظة.
- **موسيقى العود التعبيرية (Web Audio)**: توليد نغمات عود هادئة برمجياً لمرافقة القراءة دون الحاجة لملفات صوت خارجية.
- **دفتر الخواطر والتوقيعات**: إمكانية تدوين رسائل وإهداءات من الزوار وحفظها محلياً.

## 🚀 تشغيل الموقع عبر GitHub Pages
لتشغيل الموقع ونشره مجاناً عبر الإنترنت:
1. اذهب إلى إعدادات المستودع (**Settings**) في GitHub.
2. اختر من القائمة الجانبية **Pages**.
3. تحت **Branch**، اختر `main` واضغط **Save**.
4. سيظهر لك رابط الموقع المباشر لمشاركته مع أصدقائك (مثال: `https://ashrafns.github.io/za-alnoon/`).

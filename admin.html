💾 حفظ وتصدير بيانات الديوان

كافة التعديلات تُحفظ فورياً وتظهر على الموقع. يمكنك أيضاً تنزيل نسخة احتياطية أو رفع التحديثات إلى GitHub.

1. حفظ فوري على المتصفح

يتم حفظ أي قصيدة تضيفها أو تعدلها محلياً، وتظهر فوراً عند زيارة الموقع دون أي تأخير.

2. تصدير ملف القصائد (JSON)

تنزيل ملف بيانات القصائد الكاملة مرتبة من الأحدث إلى الأقدم لحفظها أو أرشفتها.

🚀 رفع التحديثات تلقائياً إلى GitHub Pages

بفضل خط الأتمتة المدمج في الموقع عبر GitHub Actions، يمكنك تشغيل ملف deploy.ps1 في مجلد المشروع، أو تشغيل سير العمل من تبويب Actions في GitHub ليتم نشر التحديثات الحية لجميع الزوار حول العالم في ثوانٍ معدودة.
